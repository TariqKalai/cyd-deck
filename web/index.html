CYD Deck

Flashe ton CYD depuis le navigateur (Chrome ou Edge, port USB branché sur cet ordinateur), puis configure-le avec la console.

1. Installer le firmware (USB)

Web Serial non supporté : utilise Chrome ou Edge sur ordinateur. Web Serial demande https:// ou http://localhost.

Cocher « effacer » remet tout à zéro (Wi-Fi et boutons compris). Sous Linux : ton utilisateur doit être dans le groupe dialout (ou uucp).
